# Papers

## MDia

[`MDia_Jul17.pdf`](MDia_Jul17.pdf) is the manuscript snapshot used to define this release's eight-stage pipeline, dialect-card contract, speaker-listener event schema, routing semantics, and sociolinguistic rule-bank reporting policy.

The filename is retained for provenance. Consult the paper's own title page and version metadata when citing a later public manuscript.

## CLSR

CLSR is described in [When LLMs Develop Languages: Symbolic Communication for Efficient Multi-Agent Reasoning](https://arxiv.org/abs/2606.29354). In this repository CLSR is implemented as MDia's homogeneous-agent, concrete-LSF-routing special case through `configs/clsr.yaml`.

Paper figures and result claims are subject to the evidence-stream and reproduction limits in [`docs/reproduction.md`](../docs/reproduction.md).
